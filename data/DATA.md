# Data

## Real data (used for all real-data results)
- Source: Yahoo Finance, downloaded with the yfinance Python library (adjusted close prices).
- Downloaded on: 07 November 2026, using scripts/download_data.py. Saved as data/prices_real.csv.
- Coverage: the 30 NSE stocks in config/universe.csv, daily prices from 2019-01-01 to 2025-12-30 (1729 trading days).
- Tickers changed from the original list: none.
- Estimation window: the first 756 trading days (up to 2022-01-20) are used to estimate expected returns and the Ledoit-Wolf covariance. The remaining 973 days are held out and not used for estimation.
- ITC.NS has a near-zero estimated annual return (0.0002) in the estimation window. This is what the data shows, not an error.
- Yahoo Finance adjusted prices can be revised over time. The committed CSV is the snapshot behind every reported real-data result.

## Transaction cost rates
- config/default.json sets buy_rate = 0.00119 (0.119%) and sell_rate = 0.00104 (0.104%).
- Estimated on 07 November 2026 from the standard Indian delivery-trade charge structure, assuming zero brokerage. Buy = STT 0.1% + NSE transaction charge about 0.003% + SEBI fee about 0.0001% + GST 18% on (transaction charge + SEBI fee) + stamp duty 0.015%. Sell = the same without stamp duty.
- These are estimates, not figures from a specific broker's charge sheet, and the component rates were not checked against a live broker page.
- Not modelled: fixed per-order charges (for example depository charges on sells), bid-ask spread, market impact, and taxes on gains.
- Scaling all rates by one constant does not change the Pareto front, so a uniform error in the overall cost level does not affect which portfolios are non-dominated.

## Synthetic data (development only)
- Generated by src/synthetic_data.py: a factor model (market + sector + stock-specific noise), seed 2026, about 6 years of daily prices.
- Not real. Every synthetic result file and figure is labelled SYNTHETIC.
